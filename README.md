# Playmancer

Mix your favorites. Find your next game.

Playmancer is a multi-seed game discovery project. Its initial product vision,
research questions, constraints, and acceptance gates are tracked in
[issue #1](https://github.com/drevendev/Playmancer/issues/1).

This commit establishes the repository base only. Product implementation,
research canon, project controls, and GitHub Pages are intentionally introduced
through reviewed follow-up pull requests.
